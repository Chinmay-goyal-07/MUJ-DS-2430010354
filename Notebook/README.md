# Notebooks

| Notebook | Description |
|---|---|
| `brain_tumor_cnn.ipynb` | Capstone: ResNet18 transfer learning with 5-fold CV, early stopping, evaluation and single-image prediction. Written for Google Colab (T4 GPU). |
| `brain_tumor_transformer.ipynb` | Same pipeline with a pretrained Swin-T (or ViT-B/16) Vision Transformer, for comparison with the CNN. |
The notebook expects a zipped dataset with `Training/` and `Testing/` folders (see the team repo's installation guide).
